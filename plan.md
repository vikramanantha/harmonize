### First Prompt to understand properly

We want to create an app that uses Bluetooth LE on phones and the Meta Muse agent.

The first part of this app is that we want phones to be able to communicate with other phones via bluetooth le. they should be able to send messages to each other

The second part is that on a phone, we want the phone to be able to communicate with the Muse agent. Not the Muse spark API, but the Muse agent in the app that has access to Instagram.

I am aware of a way to connect the Muse agent to WhatsApp. I am also aware of a way to send WhatsApp messages (Beeper does it). Thus, there should be a way to automatically talk to the Muse agent from code.

The current plan is to create two separate systems for the BT and for the Muse agent, and connect them in some way. For now, assess the ability to do either one. Take a look at https://github.com/dylankainth/blades/ to see how the bluetooth is done.
